# Corrupt-save touch options

## Objective
Make the rendered Purge and Leave rows genuine touch targets without changing their physical-button behaviour or any unrelated World Dungeon code.

## Requirements
- **CST-01** A tap inside Purge selects index 0 and commits the existing purge path.
- **CST-02** A tap inside Leave selects index 1 and commits the existing leave path.
- **CST-03** Draw and hit-test consume one shared rect helper; Up/Down/Confirm/Back remain unchanged.

## Gate
Pure real-GameRenderer hit-test harness, full host suite, one X4 Pro release build, then one Pixel/Gauge gate. Deliver the rebuilt bare app image for offset `0x10000` with esptool image-info and SHA-256.
